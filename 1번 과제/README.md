# 1번 과제 — 고속도로 교통량 데이터 기반 트렌드 분석

## 과제 개요
한국도로공사 TCS 영업소별 교통량 자료(2026년 8월~10월)를 분석하여 일별 추세, 이동평균, 요일별 차이, 전일 대비 증감률을 시각화하는 기본 과제입니다.

- 분석 기간: 2026-08-01 ~ 2026-10-31 (92일)
- 원본 관측치: 164,247행
- 구분되는 영업소 코드: 476개
- 분석 환경: Python 3.10 이상 / VS Code
- 분석 코드: `analysis.py`
- 실행: `python -m pip install -r requirements.txt` 다음 `python analysis.py`

## 중요 사항
**TCS 영업소 통과 집계건수**이며, 고속도로 구간교통량이나 고유 차량대수와 같지 않습니다. 같은 차량의 입출구 통과가 중복 계산될 수 있습니다.

원본 3개월의 서로 다른 일자는 **92개**입니다. 100개 이상의 *날짜별 시점*이 필수인 경우 2026년 7월 데이터를 추가해 분석해야 합니다.

## 사용한 원본 파일
- `TCS_영업소별교통량_1일_1개월_202608.zip`
- `TCS_영업소별교통량_1일_1개월_202609.zip`
- `TCS_영업소별교통량_1일_1개월_202610.zip`

원본 파일명은 ZIP이지만 실제 파일 내용은 gzip 압축 CSV이며 CP949로 읽습니다. 파일들은 `source/` 폴더에 배치합니다.
